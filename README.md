# موقع محمد باوني

موقع تعريفي عربي ثابت مبني باستخدام HTML5 وCSS3 وJavaScript، ومهيأ للنشر على GitHub Pages.

## الملفات
- `index.html`: محتوى الموقع وأقسامه.
- `style.css`: التصميم المتجاوب والهوية البصرية.
- `script.js`: قائمة الهاتف وسنة حقوق النشر.
- `assets/`: الصور والشعار والفيديو.
- `assets/gallery/`: صور الأنشطة والملصقات.
- `assets/documents/`: مكان مخصص للوثائق التي قد تضاف لاحقاً.

## تشغيل محلي
افتح `index.html` في متصفح حديث. يفضّل استخدام إضافة Live Server في VS Code أثناء التطوير.

## النشر على GitHub Pages
1. أنشئ مستودعاً جديداً على GitHub باسم `candidate-website` أو أي اسم تختاره.
2. ارفع جميع محتويات هذا المجلد إلى جذر المستودع، بحيث يكون `index.html` في الجذر.
3. افتح Settings ثم Pages.
4. في Build and deployment اختر Deploy from a branch.
5. اختر الفرع `main` والمجلد `/ (root)` ثم Save.
6. انتظر اكتمال النشر، وسيظهر رابط الموقع في صفحة Pages.

## ملاحظات تحريرية مهمة
- رقم المرشح مضبوط على **30** ورقم القائمة **01** وفق آخر تصحيح من صاحب المشروع.
- تم استخدام تسمية **ولاية بوسعادة** وفق تعليمات صاحب المشروع.
- البرنامج التنموي موسوم بوضوح بأنه مسودة غير معتمدة، ويجب مراجعته واعتماده قبل تقديمه كبرنامج رسمي.
- الحساب المدرج على فيسبوك هو حساب شخصي: https://www.facebook.com/mohamed.baouni
- لم تتم إضافة تواريخ أو إنجازات أو تفاصيل مهنية غير مزودة.
- الخريطة صورة بصرية أرسلها صاحب المشروع، وليست خريطة تفاعلية أو مصدراً جغرافياً موثقاً.
- تأكد من امتلاك حقوق نشر الصور والفيديو والشعارات قبل نشرها علناً.


## التفاعلات والحركات
- ظهور تدريجي للأقسام والبطاقات أثناء التمرير.
- تأثيرات تفاعلية للأزرار والبطاقات والأيقونات.
- قائمة هاتف متحركة، مع إيماءة سحب لفتحها أو إغلاقها.
- معرض صور بنافذة عرض تدعم السحب يميناً ويساراً والتنقل بلوحة المفاتيح.
- احترام إعداد `prefers-reduced-motion` لتقليل الحركة عند طلب ذلك من الجهاز.
